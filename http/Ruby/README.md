# http — Ruby

Ruby 3 (stdlib net/http)

## Usage

```text
Get(url) → { status_code, body }
Post(url, json_body) → { status_code, body|error }
```

## API

| Function | Description |
|----------|-------------|
| `Get` | HTTP GET |
| `Post` | HTTP POST |
| `Put` | HTTP PUT |
| `Delete` | HTTP DELETE |

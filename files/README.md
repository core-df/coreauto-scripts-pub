## API (all languages)

| Function | Description |
|----------|-------------|
| `LocalRead` | Read a local text file |
| `LocalWrite` | Write a local text file |
| `LocalMove` | Move/rename a local file |
| `SftpGet` | Download from SFTP |
| `SftpPut` | Upload to SFTP |
| `SftpList` | List remote directory |

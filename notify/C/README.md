# notify — C

Build: `make` (requires [http/C](../../http/C/README.md) libcurl client).

| Function | Description |
|----------|-------------|
| `notify_slack` | Slack webhook |
| `notify_teams` | Microsoft Teams webhook |
| `notify_pagerduty` | PagerDuty Events v2 |
| `notify_email` | SMTP email |

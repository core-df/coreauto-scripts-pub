## API (all languages)

| Function | Description |
|----------|-------------|
| `Slack` | Post to Slack incoming webhook |
| `Teams` | Post to Microsoft Teams webhook |
| `Email` | Send plain-text email via SMTP |
| `PagerDuty` | Trigger PagerDuty event |

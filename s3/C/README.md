# s3 — C

Uses **AWS CLI** (`aws` on PATH). See [Python](../Python/README.md) for API reference.

## Build

```shell
cd s3/C
make
```

## Functions

| Function | Description |
|----------|-------------|
| `s3_init` | Validate env |
| `s3_get_object` | Download object |
| `s3_put_object` | Upload object |
| `s3_list_objects` | List keys |
